# nw-circle

## 概要

サークル資料をクラウドで共有する

[リポジトリ構成](https://nw-circle.vercel.app/)

## リポジトリ構成

```text
.
├─ .gitignore
├─ docs_html/                     (HTML出力ファイル)
├─ images/                        (記事の使用画像)
├─ notes/                         (サークル長のナレッジ共有フォルダ)
├─ documents/                     (メイン資料集フォルダ)
├─ archives/                      (アーカイブフォルダ)
├─ articles/                      (Zennの公開記事)
├─ index.html
├─ AGENTS.md
├─ README.md
├─ package.json
├─ package-lock.json
└─ skills-lock.json
```
