# nw-circle

[リポジトリ閲覧ページ](https://nw-circle.vercel.app/)

## リポジトリ構成

```text
.
├─ .agents/                       (エージェント用スキル)
├─ .github/                       (GitHub設定)
├─ .gitignore
├─ archive/                       (アーカイブ資料)
├─ articles/                      (Zennの公開記事)
├─ books/                         (書籍関連資料)
├─ docs/                          (ドキュメント・HTML資料)
├─ docs_html/                     (HTML出力ファイル)
├─ images/                        (記事・資料で使用する画像)
├─ notes/                         (ナレッジ共有資料)
├─ tests/                         (検証用ファイル)
├─ trash/                         (一時保管ファイル)
├─ HANDOVER.md                    (引き継ぎ記録)
├─ index.html                     (トップページ)
├─ AGENTS.md
├─ README.md
├─ package.json
├─ package-lock.json
└─ skills-lock.json
```
