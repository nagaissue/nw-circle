# 後期サークル計画2026

## 概要

夏休み明けのサークルでは、当初予定していた"第2期 サーバ構築"計画を見直し、学習内容を大きく4つの要素に分ける。  

## 学習コース

### 1. 通信ネットワーク

- Ciscoのシミュレータや実機を使った学習を引き続き行う
- ネットワークの歴史を学ぶ
- OSI参照モデルの各レイヤーを体系的に学ぶ
- 内容をレイヤーごとに細分化する
- 冗長ネットワーク構築を盛り込む
- パケットトレーサーの復習問題と解答を用意する
- セキュリティ要素を取り入れる

### 2. クラウド

- AWSなどを用いたクラウド構築を行う
- ネットワークに加えた応用分野として扱う
- AWS資格取得に向けた内容を盛り込む
- 対象は主に3年生以上とし、受講にはAWSアカウントを必要とする
- マイクラサーバ構築を題材として検討する
- オンプレミス環境との連携ネットワークを扱う
- Git/GitHubを学習内容に盛り込む
- Dockerの利用を検討する

### 3. Windows / Linux OS

- LinuxやWindowsなどのOSを学習する
- Windowsターミナルの基本操作を学ぶ
- Linuxコマンドを体験しながら、docx/XMLの関係を学ぶ
- VirtualBoxやWSLの使用を検討する
- SCPを学習する
- vi/nanoを体験する
- VS Codeを使用する学習内容を取り入れる

### 4. AI

- 生成AI、AIエージェント、AI IDEなどAIの種類を学ぶ
- ローカルLLMを体験する
- Llamaなどの比較的低レイヤーのLLMを用いて、Thinkingなどの処理を目で見て学ぶ
- これまで使用してきたAIを紹介する
- Discordチャンネルに投稿したAI関連のナレッジを振り返る
- AIとOS、または通信ネットワークとAWSを組み合わせた学習も検討する
- Git/GitHubを学習内容に盛り込む

## 運営方法

- 17:00〜18:30の時間帯で実施する
- 40分・40分の2本立てを検討する
- 前半は通信ネットワークを扱う案を検討する

## その他の検討事項

- Officeソフトの便利な使い方や資料作成のコツを盛込む
- NASのメンテナンス時期を決める
- GitHub Codespacesを活用する
- VS Codeの使い方を習得する
- Google Chromeの便利な使い方を盛込む
- WindowsとLinuxの連携
- WindowsとCisco PTの連携
- NASの機能調査、利用拡大を図る
