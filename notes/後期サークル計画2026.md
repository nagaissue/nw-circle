# 後期サークル計画2026

## 概要

夏休み明けのサークルで計画していること  
後期はサーバ構築という話だったが、変更してコース分けしたい  
動画を用いてティーチングを並行して行うことを目指す

## 学習テーマ候補

1. 通信ネットワーク
   引き続き、Cisco のシミュレータや実機を使った学習を行う
   ネットワークの歴史を学ぶ
   冗長ネットワーク構築を盛り込む
2. AWS
   ネットワークに+αとして、AWS などを用いたクラウド構築も行う
   資格取得に向けた内容も盛り込む
   3~年生向け（AWSアカウント必須）
   マイクラサーバ構築したい
3. OS
   Linux や Windows などの OS の学習（主にLinux 向けのコースになる）
   Linux用のPCで実演を交える
   Linuxコマンドを体験しながらdocx/xmlの関係を学ぶ（一石二鳥）
   VirtualBox/WSLの使用検討
4. AI

## アイディア

- 17:00~18:30で40min/40minの2本立てにする
- 前半は通信ネットワーク/
- Git/GitHubはクラウドコースまたはOSコースに盛り込む
- Officeソフトの便利な使い方、資料作成のコツ
- AIとOS、通信ネットワークとAWSを一緒にするかも（いずれかのコースでAI学習を盛り込みたい）
- NASのメンテナンス実施のタイミングを考えておく
- GitHub Codespacesは毎月無料枠あり（ファイル閲覧だけなら使用必要無し）
- 今までのNotionメモを分析する
- AIコースはDiscordチャンネルにアップしたナレッジを振返る
- Dockerを盛込みたい
- VS Codeを使用する学習内容で分けてみる
