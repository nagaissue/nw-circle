## 1. 概要

- 2026年度は、Cisco Packet Tracerというシミュレータを用いたネットワーク構築を中心に、Windows/Linux OS、クラウド、AI、Git/GitHubにも触れる活動を行う。  
- 前期は、ネットワークの歴史や基礎知識、IPv4アドレッシング、ルーティング、DHCPなど、ネットワーク構築の基礎を学習した。一方で後期は、ネットワーク構築の学習を継続することに加えて、ネットワーク構築と関連する分野にも活動範囲を広げる。  
- 当初予定していたサーバ構築への全面的な移行は行わず、後期を「ネットワーク構築＋α」と位置づける。活動内容は進捗に応じて調整し、ネットワーク構築を必須分野、OS、クラウド、AI・Git/GitHubを発展分野とする。

## 3. 後期活動内容

### 3.1 ネットワーク構築（必須）

- Cisco Packet TracerとCiscoルータ・スイッチなどの実機を使ったネットワーク構築
- ネットワークの歴史とOSI参照モデル
- IPアドレッシング、ルーティング、DHCP、VLAN
- VLAN10、VLAN20、VLAN30などを用いた論理ネットワークの設計
- トランク接続と複数VLAN間の通信
- `ping` や `show` コマンドを用いた疎通・状態確認
- 冗長ネットワーク構築と、セキュアなネットワーク構築の基礎
- パケットトレーサーの復習問題と解答を用いた段階別演習

### 3.2 Windows/Linux OS（発展）

- WindowsとLinuxの歴史・特徴
- Windowsターミナルの基本操作（`ipconfig`、`tracert`など）
- Linuxのbash基本操作（`ip a`、`su`、`cd`、`cp`、`rm`、`mkdir`、`mv`、`cat`、`ping`など）
- `Ctrl+C`、`Ctrl+Z`などのプロセス操作
- Linuxディストリビューション、ディレクトリ、ユーザー、パーミッション
- リダイレクトとパイプ
- vi/vim、emacs、nanoなどのエディター
- SSH、SCP、Tera Termの基本操作
- WSL2やVirtualBoxを用いたLinux環境
- Linuxでの簡単なネットワーク構築

### 3.3 クラウド（発展）

- AWSなどを用いたクラウド構築の紹介
- AWS資格取得に向けた学習内容の紹介
- オンプレミス環境との連携ネットワーク
- マイクラサーバ構築などを題材にしたクラウド活用
- Dockerなどのコンテナ技術
- Git/GitHubとの連携

### 3.4 AI・Git/GitHub（発展）

- 生成AI、AIエージェント、AI IDEなどの概要
- ローカルLLMやLlamaなどの紹介
- Agent Skillsの作成・利用例
- Git/GitHubを用いたプログラムやプロジェクトの管理
- GitHubのIssueやPull Requestの基本
- GitHub CodespacesとVS Codeの紹介
- Discordチャンネルに投稿したAI関連のナレッジの振り返り
