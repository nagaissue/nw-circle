# 概要（後期）

夏休み明けのサークルでは、当初予定していた"第2期 サーバ構築"計画を見直し、学習内容を大きく4要素に分ける。  
後期は"ネットワーク構築+α"と題して、通信ネットワークを主として他分野に触れていく。
なお、サークル活動の進捗が下記の学習内容の進捗に影響する。

## 学習コース

### 1. 通信ネットワーク

- Cisco Packet Tracerや実機を使用したネットワーク構築の学習は継続する
- ネットワークの歴史を学ぶ
- OSI参照モデルの各レイヤーを体系的に学ぶ、レイヤーごとに深堀りする
- 冗長ネットワーク構築を盛り込む
- パケットトレーサーの復習問題と解答を用意する
- セキュアなネットワーク構築に触れる

### 2. クラウド

- AWSなどを用いたクラウド構築を行う（AWS以外の可能性は無きにしも非ず）
- AWS資格取得に向けた内容を盛り込む
- 対象は主に3年生以上とし、受講にはAWSアカウントを必要とする
- マイクラサーバ構築を題材として検討する
- オンプレミス環境との連携ネットワークを扱う
- Git/GitHubを学習内容に盛り込む

### 3. Windows / Linux OS

- LinuxやWindowsなどのOSを学習する
- Windowsターミナルの基本操作を学ぶ
- Linuxコマンドを体験しながら、docx/XMLの関係を学ぶ
- VirtualBoxやWSLの使用を検討する
- SCPを学習する
- vi/nanoを体験する
- Docker（コンテナ）に触れる

### 4. AI

- 生成AI、AIエージェント、AI IDEなどAIの種類を学ぶ
- ローカルLLMを体験する
- Llamaなどの比較的低レイヤーのLLMを用いて、Thinkingなどの処理を目で見て学ぶ
- これまで使用してきたAIを紹介する
- 自作Agent Skillsの紹介
- AIとOS、または通信ネットワークとAWSを組み合わせた学習も検討する
- Git/GitHubを学習内容に盛り込む（Codespaces活用）
- VS Codeの使用方法を学ぶ
- Discordチャンネルに投稿したAI関連のナレッジを振返る

## 運営方法

- 17:00〜18:30の時間帯で実施する
- 40分・40分の2本立てを検討する
- 前半は通信ネットワークを扱う案を検討する

## つぶやき

- Officeソフトの便利な使い方や資料作成のコツ
- NASのメンテナンス時期
- Google Chromeの便利な使い方
