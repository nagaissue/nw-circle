# 概要（後期）

2026年度はCisco Packet Tracerを用いた通信ネットワーク構築を主として、Windows/Linux OS、クラウド、AI、Git/GitHubなど、ネットワーク関連またはそれに限らず幅広い分野の学習活動を計画する。  
当初予定していた「第2期 サーバ構築」計画を見直し、後期は「通信ネットワーク構築+α」と題して、通信ネットワークを主として他分野に触れていく。

# 計画内容

## 1. 通信ネットワーク

- Cisco Packet Tracerや実機を使用した通信ネットワーク構築の学習は継続する
- ネットワークの歴史を学ぶ
- OSI参照モデルの各レイヤーを体系的に学び、レイヤーごとに深掘りする
- 冗長通信ネットワーク構築を盛り込む
- Cisco Packet Tracerの復習問題と解答を用意する
- セキュアな通信ネットワーク構築に触れる

## 2. クラウド

- AWSなどを用いたクラウド構築を行う
- AWS資格取得に向けた内容を盛り込む
- 対象は主に3年生以上とし、受講にはAWSアカウントが必要となる
- マイクラサーバ構築を題材として検討する
- オンプレミス環境との連携ネットワークを扱う

## 3. Windows/Linux OS

- LinuxやWindowsなどのOSを学習する
- Windowsターミナルの基本操作を学ぶ
- Linuxコマンドを体験しながら、docx/XMLの関係を学ぶ
- VirtualBoxやWSLの使用を検討する
- SCPを学習する
- vi/nanoを体験する
- Docker（コンテナ）に触れる

## 4. AI・Git/GitHub

- 生成AI、AIエージェント、AI IDEなどAIの種類を学ぶ
- ローカルLLMを体験する
- Llamaなどの比較的低レイヤーのLLMを用いて、Thinkingなどの処理を目で見て学ぶ
- これまで使用してきたAIを紹介する
- 自作Agent Skillsの紹介
- AIとOS、または通信ネットワークとAWSを組み合わせた学習も検討する
- Git/GitHubを学習内容に盛り込む（Codespaces活用）
- VS Codeの使用方法を学ぶ
