# 概要（後期）

2026年度はCisco Packet Tracerを用いた通信ネットワーク構築を主として、クラウド、AI、Git/GitHubなど、通信ネットワーク構築に限らず他分野の学習活動を盛込んだ計画とする。  
当初予定していた「第2期 サーバ構築」計画を見直し、後期は「通信ネットワーク構築+α」と題して、通信ネットワークを主として他分野に触れていく。

# 計画内容
各分野で取組む予定である活動事項を列挙する。

## 1. 通信ネットワーク
- ネットワークの歴史を学ぶ
- OSI参照モデルの各レイヤーを体系的に学び、レイヤーごとに深掘りする
- 冗長通信ネットワーク構築を盛り込む
- Cisco Packet Tracerの復習問題と解答を用意する
- セキュアな通信ネットワーク構築に触れる

## 2. クラウド
- AWSを用いたクラウド構築を行う
- AWS資格取得に向けた内容を盛り込む
- マイクラサーバ構築を題材として検討する

:::message
AWSアカウントが必要
:::

## 3. AI・Git/GitHub
- 生成AI、AIエージェント、AI IDEなどAIの種類を知る
- ローカルLLMを体験する
- これまで使用してきたAIを紹介する
- Agent Skillsの紹介（自作含む）
- Git/GitHubを学習内容に盛り込む
- VS Codeを活用する

:::message
GitHubアカウントが必要
:::
