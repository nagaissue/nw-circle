# 諸注意

:::message
**対象読者**
本校のNASサーバを使用するサークルメンバー
:::

:::message
**接続情報の取扱いについて**
セキュリティを考慮し、NASの接続に必要な資格情報（ネットワークパス・ユーザー名・パスワード）は原則として非公開とします。
よって資格情報は原則サークル長から取得してください。
:::

# 手順

## 手順1：エクスプローラーを検索する

PCのデスクトップ画面下部（タスクバー）にある**検索バー（虫眼鏡のアイコンが目印）**をクリックし、キーボードで **エクスプローラー**と入力します。

![NAS Access](/images/1.png)

## 手順2：エクスプローラーを起動する

検索結果に表示されたフォルダーのアイコンをした**エクスプローラー**をクリックします。

![NAS Access](/images/2.png)

:::message
エクスプローラーは**Windows**キー + **E**キーを同時に押すことでも起動できます。
:::

## 手順3：アドレスバーにパスを入力する

エクスプローラー上部にある**アドレスバー**の余白部分を一度クリックして入力状態にし、サークル長から取得したパスを入力して**Enter**キーを押します。

![NAS Access](/images/3.png)

![NAS Access](/images/4.1.png)

:::message
￥と`\`（バックスラッシュ）はフォントが異なりますが同義です。どちらで入力されても問題ありません（ただし入力は半角英数字）。
また、**接続（特に初回）時は十数秒の遅延が発生する場合があります。**
:::

## 手順4：ユーザー名とパスワードを入力する

"ネットワーク資格情報の入力"（ダイアログ）が表示されたら、資格情報を入力し、**OK**をクリックします。

![NAS Access](/images/5.2.png)

:::message
**注意**
Windowsのシステムを考慮し、ダイアログ内の「資格情報を記憶する」にはチェックしないでください。
:::
