# 2026年度ネットワークサークル活動計画

## 1. 計画の概要

2026年度は、Cisco Packet Tracerを用いたネットワーク構築シミュレーションを中心に、Windows・LinuxなどのOS、クラウド、AI、Git/GitHubにも触れる学習活動を行う。

前期は、ネットワークの歴史や基礎知識、IPv4アドレッシング、ルーティング、DHCPなど、通信ネットワークの基礎を学習した。後期は、通信ネットワークの学習を継続しながら、ネットワーク構築と関連する分野へ学習範囲を広げる。

当初予定していたサーバ構築への全面的な移行は行わず、後期を「ネットワーク構築＋α」と位置づける。活動内容は進捗に応じて調整し、通信ネットワークとOSを必須分野、クラウドとAI/GitHubを発展・紹介分野として扱う。

## 3. 後期の学習内容

### 3.1 通信ネットワーク（必須）

- Cisco Packet TracerとCiscoルータ・スイッチなどの実機を使ったネットワーク構築
- ネットワークの歴史とOSI参照モデル
- IPアドレッシング、ルーティング、DHCP、VLAN
- VLAN10、VLAN20、VLAN30などを用いた論理ネットワークの設計
- トランク接続と複数VLAN間の通信
- `ping` や `show` コマンドを用いた疎通・状態確認
- 冗長ネットワーク構築と、セキュアなネットワーク構築の基礎
- パケットトレーサーの復習問題と解答を用いた段階別演習

前期に学習したCisco Packet Tracerの基本操作、IPv4アドレッシング、RIP・OSPF、DHCPv4などを踏まえ、後期はVLANに優先して取り組む。進捗に余裕がある場合は、IPv6アドレッシング、スタティックルーティング、イーサチャネル、DHCPv6なども扱う。

### 3.2 Windows/Linux OS（必須）

- WindowsとLinuxの歴史・特徴
- Windowsターミナルの基本操作（`ipconfig`、`tracert`など）
- Linuxのbash基本操作（`ip a`、`su`、`cd`、`cp`、`rm`、`mkdir`、`mv`、`cat`、`ping`など）
- `Ctrl+C`、`Ctrl+Z`などのプロセス操作
- Linuxディストリビューション、ディレクトリ、ユーザー、パーミッション
- リダイレクトとパイプ
- vi/vim、emacs、nanoなどのエディター
- SSH、SCP、Tera Termの基本操作
- WSL2やVirtualBoxを用いたLinux環境
- Linuxでの簡単なネットワーク構築

### 3.3 クラウド（発展・紹介）

- AWSなどを用いたクラウド構築の紹介
- AWS資格取得に向けた学習内容の紹介
- オンプレミス環境との連携ネットワーク
- マイクラサーバ構築などを題材にしたクラウド活用
- Dockerなどのコンテナ技術
- Git/GitHubとの連携

AWSを利用する場合は、授業で使用しているAWSアカウントを基本とし、必要に応じて顧問へアカウント開設を依頼する。実施時期や具体的な内容は、参加者の環境と前半の進捗を踏まえて決定する。

### 3.4 AI・Git/GitHub（発展・紹介）

- 生成AI、AIエージェント、AI IDEなどの概要
- ローカルLLMやLlamaなどの紹介
- Agent Skillsの作成・利用例
- Git/GitHubを用いたプログラムやプロジェクトの管理
- GitHubのIssueやPull Requestの基本
- GitHub CodespacesとVS Codeの紹介
- Discordチャンネルに投稿したAI関連のナレッジの振り返り

現段階では、AI・クラウド・Git/GitHubは必須成果物を設定せず、紹介を中心とする。作成物やメンバーの情報はむやみに公開せず、サークルで用意したリポジトリやメンバー間での利用を基本とする。情報セキュリティを脅かす目的でAIを利用する行為は認めない。

## 4. 活動方法

### 4.1 1回の活動時間

- 活動時間は17:00～18:30を基本とする
- 通信ネットワーク40分、休憩5分、OS40分の2本立てを基本とする
- 実機構築や成果物制作の回は、進捗に応じて時間配分を変更する

### 4.2 学習の進め方

- 各分野でステップアップ形式の教材・演習を用意する
- 経験のある参加者は発展問題へ進み、苦手な参加者は基本問題を自分のペースで進める
- 自作のPowerPoint資料やZennブログ、テックブログなどの参考資料、図書・書籍を活用する
- 動画を用いたティーチングも行い、活動後の復習を可能にする

### 4.3 参加方法

- 1回目・2回目の参加は見学期間とする
- 3回目以降の参加はサークル加入を基本とする
- 参加者の希望に応じて、加入時期は柔軟に扱う
- 1・2年生にも活動内容と成果を分かりやすく伝え、継続参加につなげる

## 5. 年度末の成果物

年度末の必須成果物は、Ciscoルータやスイッチの実機を用いたVLANネットワーク構築とする。

### 完成時に確認する内容

- VLAN10、VLAN20、VLAN30などの論理ネットワークを設計できる
- スイッチ間のトランク接続を構築できる
- 構築後に`ping`や`show`コマンドで通信・状態を確認できる
- 設計、構築、トラブルシューティングの内容を説明できる
- 作業手順書と作業確認用シートを作成できる

評価はサークルメンバー全員と顧問が行う。学校の授業のような厳格な採点ではなく、設計・構築・問題解決の過程を重視する。
